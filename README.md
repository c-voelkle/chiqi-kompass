# CH-IQI Kompass

Prototyp zur Einordnung der CH-IQI-Qualitätsindikatoren der Schweizer Akutspitäler:

- **Cockpit QIP 2024**: O/E-Radar, Funnel-Plot mit frei wählbaren Vergleichsgruppen
  (Spitaltyp, Region, Grösse, Leistungsprofil), Trends und Fallzahl-Monitor auf Basis
  der BAG-Publikation.
- **Unterjährige Auswertung**: eigene SpiGes-Daten lokal im Browser auswerten, nach
  Patientengruppen filtern, mit dem BAG-Verlauf vergleichen; QM-Workbench mit
  Fallreview, PDCA und Nachweis. Es werden keine Daten übertragen.

Online: https://c-voelkle.github.io/chiqi-kompass/

Die App liegt in `deploy/` und wird automatisch veröffentlicht. Struktur und Pflege:
`ANLEITUNG.md`; Hinweise für Mitwirkende und Prüfungen: `AGENTS.md`; Gestaltung:
`docs/DESIGN_LANGUAGE.md`.

Statistische Auffälligkeit ist ein Prüfhinweis, kein Qualitätsurteil.
